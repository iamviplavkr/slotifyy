# 🚗 Slotify – Smart Parking Management System

## 📱 Android Application (Frontend)
Built using:
- Kotlin
- MVVM Architecture
- Firebase Phone Authentication (OTP)
- Retrofit
- QR Scanner
- Admin & User Modules

---

## 🌐 Backend (ASP.NET Core Web API)
Built using:
- .NET 8
- ADO.NET
- SQL Server
- Stored Procedures
- JWT Authentication
- Firebase Admin SDK

---

## 🔐 Features
- OTP Login using Firebase
- Role-based Access (User / Admin)
- Slot Booking
- QR Code Entry
- Payment Module
- Revenue Dashboard
- Slot Management
- User Management

---

## 🛠 Tech Stack
- Android (Kotlin)
- Firebase Auth
- ASP.NET Core Web API
- SQL Server
- GitHub
