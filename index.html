SLOTIFY – SMART PARKING
MANAGEMENT SYSTEM

Slotify is a real-time smart parking system that allows users to book parking slots digitally, temporarily lock slots during payment, complete transactions, and receive a QR code for entry verification. The system prevents double booking and ensures fair slot allocation using a time-based lock mechanism.

Problem Statement

Urban areas face parking issues due to lack of real-time availability and inefficient booking systems. Users often waste time searching for parking and face conflicts when multiple users attempt to book the same slot.

Literature Review

Existing systems provide static parking data and lack real-time updates, slot locking, and secure booking validation.

Core Innovation: Slot Locking

When a user selects a slot, it is locked for 5 minutes. If payment is completed → booking confirmed. If not → automatically cancelled and released.

SYSTEM ARCHITECTURE

DATABASE

Stores users, slots, bookings, and payment details.

BUSINESS LOGIC

Handles slot locking, booking validation, payment simulation, and status updates.

ANDROID APP

Kotlin-based app with booking, payment, QR generation, and admin scanning features.

BOOKING WORKFLOW

Select Slot
Slot Locked (5 min)
Payment
Confirmed

QR Verification

After payment, a QR code is generated containing booking ID and timestamp. Admin scans the QR to validate and activate the booking at entry.

RESULTS & ANALYSIS

The system successfully implements real-time booking, slot locking, payment simulation, and QR verification. It prevents double booking and automatically cancels unpaid reservations.
